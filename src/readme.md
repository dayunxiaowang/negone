# NegOne Source
This directory stores all codes of NegOne. \
This file briefly explains the folders in this directory.

# Folders
`booting` is the directory that contains codes to load the NegOne program. \
`disasm` is the directory that contains the Disassembler Engine for NegOne. \
`drv_core` is the directory that contains the drivers for external hardware which NegOne may have to take control over. \
`include` is the directory that contains the development kit headers for NegOne's virtualization core engines. \
`mshv_core` is the directory that contains the Microsoft Hypervisor Functionality Engine. \
`svm_core` is the directory that contains the AMD-V Virtualization Engine. \
`vt_core` is the directory that contains the Intel VT-x Virtualization Engine. \
`xpf_core` is the directory that contains cross-platform utilities.
